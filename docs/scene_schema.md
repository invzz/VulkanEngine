# Scene.json (Authoring) — Schema & Notes

This document specifies the authoring `Scene.json` format and the generated `scene_lightmaps.json` manifest produced by the LightMapBaker tool.

Overview
--------
- `scene.json` is intended for authors and should be edited by hand or a level editor.
- `scene_lightmaps.json` is generated by the baker and contains **bindings** between instances and lightmap assets. Keep this separate from authoring to avoid merge conflicts and accidental rebakes.

Top-level `scene.json` (example)
```
{
  "version": 1,
  "assets": {
    "models": [ "models/car.gltf" ],
    "textures": []
  },
  "objects": [
    {
      "id": "object_01",
      "mesh": "models/car.gltf",
      "material": "mat_01",
      "transform": {
        "translation": [0.0, 0.0, 0.0],
        "rotation": [0.0, 0.0, 0.0, 1.0],
        "scale": [1.0, 1.0, 1.0]
      },
      "lighting": { "mobility": "Static" }
    }
  ],
  "lights": []
}
```

Generated `scene_lightmaps.json` (example)
```
{
  "version": 1,
  "lightmapBindings": {
    "object_01": {
      "lightmapId": "lm_000",
      "uvChannel": 1,
      "uvScale": [0.25, 0.25],
      "uvOffset": [0.5, 0.0]
    }
  },
  "lightmaps": [
    {
      "id": "lm_000",
      "file": "lightmaps/lm_000_atlas.vtex",
      "format": "vtex",
      "resolution": [2048, 2048],
      "paddingPx": 8,
      "usage": "Lightmap"
    }
  ]
}
```

Notes & rules
--------------
- `scene.json` should remain authorable text and **must not** be modified by the baker; the baker writes `scene_lightmaps.json`.
- `uvChannel` is the UV set used for lightmaps (default: 1).
- `usage` is the VTEX usage semantic (see `VTexUsage` in project code).
- Bakers should write provenance fields (`createdBy`, `hash`) into the generated manifest.

Validation
----------
- Use JSON Schema (draft-07) for schema validation in tools and CI. Keep versioning at top-level (e.g., `version: 1`) for future migrations.

Appendix: Minimal JSON Schema (starter)
```
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "Scene",
  "type": "object",
  "required": ["version", "objects"],
  "properties": {
    "version": {"type": "integer"},
    "assets": {"type": "object"},
    "objects": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["id", "mesh", "material"],
        "properties": {
          "id": {"type":"string"},
          "mesh": {"type":"string"},
          "material": {"type":"string"},
          "transform": {"type":"object"}
        }
      }
    }
  }
}
```
